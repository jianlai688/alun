## 4. 10 并发压测

命令：

```powershell
python -m alun.scripts.quality_stress --mode parse --concurrency 10 --base-url http://127.0.0.1:8011
```

环境：PostgreSQL + Redis Streams + MinIO；4 个 worker；上传 10 份独立 PDF（追加不同尾部字节绕过去重）。

| 指标 | 结果 |
|---|---:|
| 总任务 | 10 |
| 成功 | **10 / 10** |
| 失败 | 0 |
| P50 墙钟 | 223.44 秒 |
| P95 墙钟 | **278.47 秒** |
| 最大 | 278.47 秒 |

说明：本轮为完整 PDF 解析（含知识点抽取）串行/并行混合负载，P95 受单机 CPU 与模型网关抽取延迟影响；队列本身未丢任务，4 个 worker 均实际消费（3/3/2/2）。原始报告：`alun/data/quality/stress-20261106-124339.md`。

## 5. 对象存储

- 上传文件写入 `alun-documents` bucket，key 为 `doc_xxx.<ext>`；
- 本地保留缓存，换节点时 `storage.get()` 可从 MinIO 拉取；
- 已验证 `put → list → get`，上传的 `doc_110f8776a1.md` 对象存在且可读；
- 迁移后将原有 12 个上传文件同步到 MinIO，平台服务读取 `doc_37b9cbf889` PDF 返回 200（1,249,325 bytes）；
- 未配置 S3 时自动回退本地 `data/uploads`。

## 6. 队列

- `ALUN_QUEUE_BACKEND=redis` 时 `pipeline.start_parse` 改为 XADD `alun:jobs`；
- worker 通过 consumer group 消费，任务状态仍写 `task` 表；
- 压测上传 10 个任务全部经队列完成；
- 健康检查返回 pending 深度（修复了把 stream 历史长度误当 pending 的问题）。

## 8. 安全基线

- 平台模式强制 `ALUN_AUTH_SECRET` 非默认值，否则启动失败；
- 登录限流 10 次/分钟/IP，Redis 不可用时进程内兜底；
- 安全响应头：`X-Content-Type-Options`、`X-Frame-Options`、`Referrer-Policy`、`Permissions-Policy`；
- CORS 从 `*` 收紧为 `ALUN_CORS_ORIGINS` 白名单；
- 上传大小限制、扩展名校验、PDF magic bytes 校验、参数化 SQL、RBAC（admin/teacher/user）；
- 生产需替换 `.env.platform.example` 中所有默认密码和 JWT secret。

## 9. pgvector 语义检索

- `POST /api/v1/documents/{id}/embeddings`：把 chunk 写入 `document_embedding`；
- `GET /api/v1/search/semantic?q=...&document_id=...`：cosine 距离检索；
- 已索引 `doc_37b9cbf889` 33 个 chunk，检索「GRPO 优势估计」返回 3 条相关片段；
- embedding 为 384 维确定性哈希基线，便于离线回归；生产可替换为模型 embedding，接口不变。

## 10. 运行方式

基础设施（Docker Compose）：

```powershell
docker compose -f alun/platform/docker-compose.yml up -d postgres redis minio
```

本地平台模式（当前验收使用）：

```powershell
$env:ALUN_DB_BACKEND="postgres"
$env:ALUN_DATABASE_URL="postgresql://alun@127.0.0.1:55432/alun"
$env:ALUN_REDIS_URL="redis://:123456@127.0.0.1:6379/1"
$env:ALUN_QUEUE_BACKEND="redis"
$env:ALUN_S3_ENDPOINT="http://127.0.0.1:9000"
$env:ALUN_S3_ACCESS_KEY="alun"
$env:ALUN_S3_SECRET_KEY="alun_dev_password"
$env:ALUN_AUTH_SECRET="<random-secret>"
python -m uvicorn alun.app.main:app --host 127.0.0.1 --port 8011
python -m alun.platform.worker worker-1
```

迁移/回滚：

```powershell
python -m alun.platform.cli status
python -m alun.platform.cli migrate
python -m alun.platform.cli rollback --target 0
```

## 12. 边界与后续

1. PG 适配层兼容 SQLite 风格 `?` 占位符，未做 PG 原生性能调优；复杂报表查询仍应按 PG 执行计划优化。
2. 当前向量 embedding 是确定性哈希基线，不是语义模型 embedding；替换后需重建索引并重新评估召回。
3. Redis 本机为 5.0.14（仅 RESP2），compose 使用 7-alpine；生产建议 Redis 7 + Sentinel/Cluster。
4. MinIO 当前为开发凭据，生产需接入正式对象存储、生命周期与加密策略。
5. 10 并发压测是单机 4 worker 结果，P95 278.47 秒；V2.1 应做 worker 水平扩展、模型调用并发池和解析缓存。
6. 尚未完成多租户隔离渗透测试、密钥轮换、备份恢复演练；这些属于生产上线前 checklist。
