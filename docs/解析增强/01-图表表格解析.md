# 图表/表格解析增强

- 问题：图片型表格（截图、扫描页、PDF 中嵌入的表格图片）在「结构树」里没有表格节点，正文只显示散落的文字，属于「无法解析图表」。
- 根因：
  1. `page.find_tables()` 只能识别 PDF 文本层/矢量表格，识别不了嵌入图片；
  2. OCR prompt 只要求「保留表格单元格」，模型通常输出普通文本行，没有 Markdown 表格结构；
  3. `attach_table_and_formula_nodes` 只把表格块挂到已有的「表 x」题注节点，没有题注的表格会被丢弃。

## 修复

1. OCR prompt 明确要求：识别到表格时输出 Markdown 表格（表头 + 每行单元格）；图表输出标题、坐标轴、图例、数据标签。
2. 新增 `_markdown_tables()`：从 OCR 输出恢复 Markdown 表格，要求至少 2 行、2 列，避免把正文竖线误判为表格。
3. 表格块去重后，若没有对应「表 x」题注节点，自动补建 `node_type="table"` 的表格节点（标题 `表格 N`），挂到最近章节。
4. 对「文本层正常但页面嵌有大图」的 PDF，`ocr_pdf_pages` 会补做 OCR（页面大图面积超过阈值且 `find_tables()` 为空），避免只走文本层漏掉图片表格。

## 图表数据提取模型

- 配置：`chart.enabled`、`chart.model`（默认 `cn:deepseek-v4-flash`，可换视觉模型）、`chart.max_pages`、`chart.dpi`；
- 解析时对图片/大图页面调用视觉模型，要求输出 JSON：图表类型、标题、坐标轴、单位、categories、series/values、confidence；
- 模型输出规范化为 `chart` 节点，节点文本包含 Markdown 数据表和 `chart-data` JSON：
  - `GET /api/v1/documents/{id}/charts` 查询已提取图表；
  - `POST /api/v1/documents/{id}/charts/extract` 触发文档重解析；
- 无图表/纯表格页面模型返回 `is_chart=false`，不会误建图表节点。

合成柱状图验收（`chart-test.png`）：模型返回 `bar`、`categories=[2021,2022,2023]`、`series=[Revenue: 12,25,18]`，生成 `chart` 节点。

界面效果：`../screenshots/22-chart-data.png`。

单元测试：`python -m unittest discover -s alun/tests -t . -q`，共 **25 项通过**。

## 使用

- 新上传图片/PDF：直接解析即可；
- 已入库文档：打开文档页点击「重新解析」，解析完成后结构树会出现「表格 N」节点；
- 表格节点文本为 Markdown 表格，可被知识点抽取、出题与 AI 检索使用。

## 边界

- OCR 识别质量取决于图片清晰度与模型；低清扫描件可能仍有错字，需人工复核。
- 复杂合并单元格/跨页表格会被模型展平为行列文本，暂不保证合并单元格语义。
- 纯统计图（柱状图/折线图）目前输出图表文字标签，不生成可计算的数据表；后续可接入图表数据提取模型。
