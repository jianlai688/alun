# A论 V1.1 黄金集与标注手册

> 文档编号：A-LUN-QA-001  
> 版本：v1.0（2026-11-06）  
> 适用阶段：V1.1 质量与验收（W1—W4）

## 1. 目的

把“感觉能用”变成“数据证明能用”。黄金集是解析、生成、判分三条链路的共同参照物：
同一道题、同一份文档、同一套口径，每次改动后都能一键回归，指标可追溯到分子/分母与样本清单。

本手册规定：

1. 黄金集的样本构成与文件格式；
2. 标题边界、层级、页码的标注规则；
3. 知识点、证据、标准答案与评分 rubric 的标注要求；
4. 题目可答性（1—5 分）与主观题一致性的评分口径；
5. 评测脚本、指标公式与通过线。

## 4. 标题标注规则

### 4.1 边界（boundary）

- 标题文本从编号开始，到标题语义结束；**包含编号**，不含句末标点。
- 跨行标题合并为一条：如“1 CLIP 引导与 Mamba-KAN 协同的医 / 学图像分割模型”应标注为完整标题。
- 不标注：图/表题注（“图 1 …”“表 2 …”）、页眉页脚、作者与单位、摘要/关键词标签、参考文献条目、正文中的编号列表（1）、2）…）。
- 摘要、关键词、参考文献、作者简介作为特殊节点单独统计，不进入标题 F1 的分母。

### 4.2 层级（level）

- 以编号深度为准：`1` → 1 级，`1.1` → 2 级，`1.1.1` → 3 级，最多 4 级。
- 中文编号：`一、` → 1 级，`（一）` → 2 级，`1.` → 3 级（政策文本按实际层级标注）。
- 无编号的报道/评论小标题统一记为 1 级。
- 编号跳号（如 2.2.3 后直接 2.2.5）按原文标注，不补造；但需在 `annotation.notes` 说明。

### 4.3 页码（page）

- 1-based，取标题**起始页**；跨页标题取起始页。
- 标题与正文同页时，页码以 PDF 阅读器显示页为准（封面计为第 1 页）。
- 允许评测时 ±1 页的边界容差；超过 ±1 页记为边界错误。

### 4.4 匹配与 F1

评测采用“标题主体归一化 + 相似度 + 页码惩罚”的一对一匹配：

- 归一化：NFKC、去空白与标点、去编号后比较主体；
- 相似度 ≥0.80 且页码差 ≤1 页视为匹配；
- `P = 匹配数 / 解析标题数`，`R = 匹配数 / 黄金标题数`，`F1 = 2PR/(P+R)`；
- 另报 `boundary_accuracy`（匹配对中页码差 ≤1 的比例）与 `level_accuracy`（层级一致比例）；
- 单篇 F1 <0.95 进入规则/人工校正；整体目标 ≥0.95。

## 5. 知识点、证据与题目标注

### 5.1 知识点（KP）

每条 KP 至少包含：

| 字段 | 要求 |
|---|---|
| `name` | 可独立命名的概念/方法/数据/结论/观点/局限 |
| `kp_type` | concept / method / data / conclusion / viewpoint / limitation |
| `node_id` 或章节标题 | 必须能回到结构树节点 |
| `definition` | 1—3 句，能被原文证据支持 |
| `importance` | 0—1；决定出题权重 |
| `difficulty` | 1—5；决定目标难度 |

### 5.2 证据（evidence）

- `quote` 必须与原文**逐字一致**（允许空白差异，不允许改写、拼接、补全）。
- `page` 必须落在证据所在页；跨页引文拆成两条。
- 证据强度：strong（直接支撑答案）/ medium（需要一步推理）/ weak（仅背景）。
- 生成题目时 V1 校验强制要求引文存在于节点原文；黄金集统计“证据支持率”时同时检查节点与全文。

### 5.3 标准答案与 rubric

- 客观题：`answer.value` 为选项 key（多选为 key 数组）或布尔值/填空词；必须唯一、可判定。
- 主观题：`answer.value` 为参考答案；`rubric` 为 2—3 条可核对要点，每条带权重。
- 评分维度固定为：要点覆盖 50%、准确性 25%、证据引用 15%、表达结构 10%。

### 5.4 题目可答性（1—5 分）

3 名评审独立打分，取每题均分；目标 ≥4.3。评分锚点：

| 分值 | 锚点 |
|---:|---|
| 5 | 题干自足、答案唯一、证据充分、干扰项合理，读题即可作答 |
| 4 | 基本可答，个别措辞需回原文确认 |
| 3 | 需要额外上下文或存在轻微歧义 |
| 2 | 答案不唯一/证据不足，需改写 |
| 1 | 无法作答或题干与证据不匹配 |

### 5.5 主观题一致率

同一答案分别由人工与模型评分（0—100）：

- `一致`：`|human - model| ≤ 10`；
- `一致率 = 一致样本数 / 总样本数`，目标 ≥85%；
- 同时报告 MAE、最大差值；最大差值目标 ≤10 分（V1.1 任务表 V11-05 的“极差 ≤5 分”按 rubric 维度分另行统计）。

## 6. 双人标注与仲裁（执行规范）

1. **抽样**：每个版本抽取 20% 样本做双人独立标注；V1.1 首批至少覆盖 2 篇研究论文 + 1 篇综述 + 1 篇政策/报道。
2. **独立**：两名标注人不见对方结果；第三人（QA）负责仲裁。
3. **仲裁**：标题边界/层级分歧以 PDF 版式与编号为准；证据分歧以原文逐字比对为准；无法一致的样本记入 `badcase` 并排除出指标分母，同时在报告中披露。
4. **留痕**：`annotation.annotator`、`annotated_at`、`notes` 必须填写；仲裁记录进 `quality_review` 或 `docs/质量/仲裁记录.md`。

> 当前状态：本版由 1 名标注人完成 7 篇人工核对 + 1 篇原生书签交叉校验；**20% 双人标注尚未执行**，是 V1.1 的待补项（见验收报告“待补证”）。

## 7. 评测脚本

在 `D:\AI论文` 下运行：

```powershell
# 全量评测并生成 Markdown 报告
python -m alun.quality.cli run --suite all --report

# 只跑结构
python -m alun.quality.cli run --suite parse

# 查看黄金集清单与校验
python -m alun.quality.cli golden

# 并发压测
python -m alun.scripts.quality_stress --mode parse --concurrency 10
```

指标口径：

| 指标 | 公式/来源 | 目标 |
|---|---|---|
| 标题 F1 | 匹配对 /（解析数、黄金数） | ≥0.95 |
| 文本覆盖率 | 节点文本（含标题）字符 / 清洗后正文行字符；学术 PDF 第 1 页封面与英文对照摘要不计入分母 | ≥0.98 |
| 表格/图表覆盖 | 解析节点数 / 题注数 | ≥0.90 |
| 证据支持率 | 引文可在原文定位的题数 / 总题数 | 100% |
| 节点可追溯率 | 引文在所属节点且页码在范围内 / 总题数 | 100% |
| 首轮失败率 | 首轮未过 V1—V8 / 非兜底生成次数 | 跟踪，目标下降 |
| 主观题一致率 | 差值 ≤10 分样本 / 总样本 | ≥85% |
| 可答性 | 3 名评审均分 | ≥4.3 |
| 30 页解析 P95 | 流水线埋点 | ≤90 秒 |
| 生成 P95 | ai_audit.latency_ms | 较基线下降 ≥50% |

4. **人工判分**：主观题一致率当前只有内部参考分（`qa-reference`），需补 3 名评审的独立评分。
