# 阅读器划词自动 AI 解读

## 功能

在阅读器左侧选中一段原文后，可以把选区发给 AI，并在右侧解读栏回答：

- 选区长度 6—400 字；
- 默认不自动发送：选中后浮出「AI 解读」按钮，点击才调用模型；
- 如需要自动，可点顶部「自动解读」开启；仅对完整句子（≥10 字且有句末标点或 ≥18 字）在 1.2 秒后发送，避免划一个字就触发；
- 提示词带当前页码，要求解释含义并说明上下文关系；
- 回答继续使用现有的原文引用与页码校验链路。

## PDF 说明

Chrome/Edge 内置 PDF 阅读器是独立插件，网页无法读取其中的选区。因此 PDF 文档默认仍显示原始版式，并提供「划词模式」按钮：

1. 点击「划词模式」；
2. 左侧显示原始 PDF 页图片，并叠加透明可划选文本层（版式、公式、图表与原文一致，不再用解析后的正文替代原文）；
3. 选中句子后点「AI 解读」；开启自动解读后才会自动发送；
4. 再点「原文模式」可回到原始 PDF。

Markdown、DOCX、TXT 等文本阅读器直接支持划词，无需切换。

## 实现

- 在 `.reader-text` 内监听 `mouseup`、键盘选区与 `copy` 事件；
- 用 `window.getSelection()` 获取选区，限制长度并定位浮层提示；
- 复用 `/api/v1/assistant/chat`，附加 `document_id` 与当前页；
- 增加 PDF 的 `readerTextMode` 切换；文本层通过 `/api/v1/documents/{id}/pages/{page}/text-layer` 返回原始页图片和按 PDF 坐标定位的透明文本行，保证显示与原文一致。

界面效果：`../screenshots/24-pdf-faithful-layer.png`。

## 验收

- `node --check alun/web/app.js` 通过；
- 选区旁显示「AI 解读」按钮，点击后右侧出现回答；开启自动解读时显示「AI 正在解读…」；
- PDF 切换到划词模式后可正常选中并触发。
