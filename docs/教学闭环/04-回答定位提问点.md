# AI 回答完成后定位到提问点

- 现象：右侧「A论 AI 解读」回答较长时，消息区自动停到底部，看不到提问位置和回答开头。
- 修复：`reader-messages` 在用户发送问题时记录该条提问的 DOM 节点；回答完成或失败后，滚动到该提问节点顶部（保留约 10px 间距），而不是继续停留在底部。
- 用户消息发送时仍滚动到底部；回答生成中的 spinner 仍在底部；完成后再回到提问点。
- 适用范围：普通提问、划词自动解读、图片提问均复用同一个 `ask()` 流程。

代码位置：`alun/web/app.js` 的 `append()`、`scrollToQuestion()` 与 `ask()`。

验证：提问后回答完成，提问气泡位于消息区顶部，回答从开头展示；js 语法检查通过，25 项测试通过。
