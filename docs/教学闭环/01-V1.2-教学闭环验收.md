## 2. 数据模型

- `follow_up`：`follow_up_id / session_id / turn_id / kind / question / answer / score / feedback / hit / miss / status`
- `paper_assignment`：`assignment_id / paper_id / doc_id / teacher_id / assignee_id / due_at / status / session_id / score / report_id / teacher_comment`
- `reader_state`：`user_id + doc_id` 主键，记录 `page_no / scroll_ratio / zoom`
- `reader_note`：页级笔记，含 `quote / note`
- `document_version`：按 `doc_id + version_no` 唯一，快照包含 `node / chunk / knowledge_point / evidence`
- `session.assignment_id`：标记题卷会话，学生端显示「老师题卷」

## 7. 兼容与边界

1. 教师端复用管理控制台外壳，路径为 `/teacher`；管理员仍可从 `/admin` 进入全部功能。
2. 题卷目前从论文的 `active` 题目中按题量抽取，尚未提供逐题手工挑题/组卷排序编辑器；后续可加「题卷编辑器」。
3. 作业按「单个学生」布置，尚未实现班级/分组批量布置；`paper_assignment` 已预留 `tenant_id`，可扩展 `class_id`。
4. PDF 页码定位依赖浏览器内置 PDF 查看器的 `#page=` 参数；不同浏览器对页码起始索引可能有一页差异，文字型文档使用结构节点页码滚动。
5. 结构版本快照包含节点、块、知识点、证据；不包含原文件二进制与题目版本，回滚后通过 `repair_questions_for_document` 重新绑定题目节点。
6. 追问评分目前仍由模型判定，未纳入总成绩；报告仅展示追问次数与均分，符合「追问不计入本轮总分」的产品约定。
