# 阅读器图片粘贴修复

- 现象：在阅读器右侧「A论 AI 解读」输入框粘贴截图没有反应。
- 原因：全局 A论 AI 抽屉绑定了 paste 事件，但阅读器自己的 `#reader-input` 没有绑定；发送时也只传 `message`，没有传 `images`。
- 修复：
  1. 阅读器新增「＋ 图片」上传按钮和隐藏 file input；
  2. `#reader-input` 监听 paste，读取 clipboard 中的 image/* 文件；
  3. 最多 3 张、单张 ≤ 8 MB，显示缩略图并可移除；
  4. 发送时以 multipart 追加 `images` 字段，后端 `/api/v1/assistant/chat` 已支持图片 data URL；
  5. 图片-only 发送时自动使用「请描述这张图片…」提示词。

验证：后端 `/api/v1/assistant/chat` 带 `images` 调用返回 200，模型能描述柱状图并区分文档内容；25 项测试通过。
