# 停止当前 AI 回答

- 阅读器 AI 解读输入框右侧新增「■ 停止」按钮，仅在回答生成中显示。
- 点击后通过 `AbortController` 取消当前 `/api/v1/assistant/chat` 请求：
  - 移除「正在读原文…」状态；
  - 在消息区追加「已停止本次回答。」；
  - 恢复发送按钮，可立即继续提问；
  - 已停止的请求不会写入消息记录。
- 普通提问、划词解读、图片提问共用 `ask()`，都会显示停止按钮。

界面效果：`../screenshots/26-stop-answer.png`。

说明：停止是前端取消等待；服务端已经发出的模型网关请求可能继续完成，但结果不会进入当前对话。
